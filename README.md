# 🍔 La Pasadita | Pedido Móvil

Aplicación web responsive para realizar pedidos de comida de forma rápida, visual y optimizada para dispositivos móviles.

---

## 📱 Descripción

**La Pasadita** es una interfaz web diseñada para facilitar pedidos de comida desde smartphone, permitiendo al usuario:

- Explorar un menú visual por categorías
- Seleccionar productos con control de cantidad
- Agregar datos de envío
- Calcular automáticamente el total (productos + envío)
- Enviar el pedido directamente por WhatsApp

El sistema está pensado para una experiencia rápida, intuitiva y sin fricción.

---

## 🚀 Funcionalidades principales

### 🧾 Menú dinámico
- Categorías organizadas (hamburguesas, extras, bebidas, postres, etc.)
- Tarjetas visuales con imagen, descripción y precio
- Control de cantidad por producto

### 🛒 Carrito de compras
- Vista flotante accesible
- Cálculo automático de:
  - Subtotal
  - Envío
  - Total final
- Eliminación de productos

### 🚚 Sistema de envío
- Selección de zonas con costo variable
- Integración directa en el total

### 📩 Integración con WhatsApp
- Generación automática del mensaje de pedido
- Redirección directa a WhatsApp con:
  - Datos del cliente
  - Dirección
  - Detalle del pedido
  - Total

### 🎨 UI/UX optimizada
- Diseño mobile-first
- Estética moderna con colores personalizados
- Animaciones suaves y layout responsivo
- Hero con video de fondo

## ⚙️ Cómo usar

1. Abre el archivo `index.html` en tu navegador
2. Selecciona productos del menú
3. Ingresa tus datos de envío
4. Elige tu zona
5. Abre el carrito
6. Haz clic en **"Proceder con el Pago"**
7. Se abrirá WhatsApp con tu pedido listo para enviar

---

## 📌 Características destacadas

- No requiere backend
- Funciona completamente en cliente (frontend)
- Ideal para negocios pequeños o ventas locales
- Fácil de personalizar (menú, precios, zonas)
